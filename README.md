# 🏠 Projetos para Casa — Modelos 3D

Peças e conjuntos que desenvolvi para resolver necessidades de casa: organização, manutenção de
equipamentos, acessórios e utensílios. Modelados no **SolidWorks**, prontos para **impressão 3D**.

---

Conjunto com base, fechadura, o-ring e pinos, com versão otimizada para impressão e renderings.

## 🖨️ Como usar

| Formato | Para quê |
|---|---|
| `.SLDPRT` / `.SLDASM` | Editar no SolidWorks |
| `.STL` / `.obj` | Imprimir (o GitHub mostra o visualizador 3D ao abrir o arquivo) |
| `.ipt` / `.iam` | Autodesk Inventor |
| `.gx` / `.fpp` | Projetos prontos do FlashPrint |
